## 8장 아키텍처에 넣을 정확한 내용

```text
브라우저
  → Amazon EC2(ap-northeast-2)
      nginx :80 → Next.js :3000
      ├─ SQLite: 사용자·프로필·시간표·체크리스트·팁·질문로그·포인트
      └─ FAISS sidecar :8788
           → EC2 로컬 index.faiss + chunks.jsonl
           → Bedrock Titan Text Embeddings v2: 질문 임베딩
  → Amazon Bedrock Claude: 추천 이유·근거 기반 답변 생성

계획됨 / 현재 런타임 미연결
  Amazon S3 documents/ → 수동 인덱서 → EC2 로컬 FAISS 재생성
```

발표 문장:

> 질문이 오면 EC2 안의 FAISS가 공식 근거를 먼저 찾고, 근거가 있을 때만 Bedrock Claude를 호출합니다. S3 문서 동기화와 재색인은 수동 운영 단계이며 현재 웹 런타임에는 연결하지 않았습니다.

1. `3-5 아키텍쳐 / 설명 ~~~` 자리표시자가 남아 있다.
2. 빨간 수정 메모와 코멘트가 최종 문서에 그대로 존재한다.
3. `S3에는 정제된 강의 데이터를 저장`이라고 현재형으로 말하지만, 현재 배포의 S3에는 강의계획서 PDF가 없고 웹·sidecar 런타임에도 연결되지 않았다.

5. 번호가 `3-1 → 3-2 → 3-4 → 3-5 → 3-5`로 중복·누락된다.
6. `이였습니다`, `한번 쯤`, `이번주`, `확인 할 수`, `추천했는질` 등 맞춤법·조사 오류가 남아 있다.
