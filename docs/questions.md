## 미결정 항목

## 확정된 답변
- 제품: CURI 강의계획서 기반 AI 수업 내비게이터
- 데모 과목: 실제 강의계획서가 있는 `웹컨텐츠개발`
- 문서 출처: 개인정보를 제거한 실제 강의계획서 파생 데이터 + 표시된 가상 보충 공지·실습 안내문
- 출처 표시: `실제 강의계획서`와 `데모 데이터`를 답변·로드맵·이번 주 코치에서 항상 구분
- 기술 구조: Next.js App Router 모노리스 + SQLite + S3 + Amazon Bedrock
- AWS 인증: Access Key 없이 조별 EC2 인스턴스 역할
- 수강생 팁 데모: 구조화 입력 후 집계 즉시 갱신
- 공개 기준: 과목별 5건 이상
- 입력 형식: 자유서술 없이 3단계 척도 3개와 선택형 준비 태그
- 데모 시드: 12건, `데모 데이터` 표시
- 공식 정보와 수강생 경험정보: 저장·표시·AI 근거를 분리
- 중복 제출 제한: 브라우저 세션당 과목 1회
- 실제 운영 로그인·신고·검토: MVP 범위 밖
- 에브리타임 및 외부 강의평 크롤링: 금지
